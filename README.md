## 🛰️ L'observatoire

<img src="https://raw.githubusercontent.com/LaFicelleCmoi/LaFicelleCmoi/telemetry/observatory.svg" width="100%" alt="Console d'observatoire live : catalogue de mes dépôts classés par commits avec leur classe spectrale selon leur fraîcheur, compte à rebours du prochain lancement orbital réel, phase de la Lune du soir et nombre d'humains en orbite, courbe de lumière de mes contributions sur 60 jours." />

**Ce n'est pas une capture d'écran.** Un script maison redessine cette console deux fois par jour avec mes vraies stats GitHub, **le prochain lancement de fusée sur Terre** et la Lune de ce soir.

</div>

<details>
<summary><b>🔧 Comment cette console se fabrique toute seule</b></summary>

<br>

Aucun service de cartes, aucune image figée : un script Node de **zéro dépendance**, lancé par GitHub Actions.

| Étape | Ce qui se passe |
|---|---|
| **1. Acquisition** | API GitHub GraphQL → mes dépôts, leurs commits, mon calendrier de contributions |
| **2. Acquisition** | API [Launch Library 2](https://thespacedevs.com/llapi) → les prochains lancements orbitaux et le nombre d'humains actuellement dans l'espace |
| **3. Calcul** | La phase de la Lune n'est téléchargée nulle part : elle est **calculée** à partir du cycle synodique (29,53 jours) |
| **4. Dessin** | Le script écrit le SVG à la main : catalogue, compte à rebours, disque lunaire, courbe de lumière |
| **5. Publication** | Dépôt sur la branche `telemetry`, que ce README affiche |

Si Launch Library ne répond pas, le panneau annonce une **liaison descendante coupée** plutôt que d'afficher une fusée déjà partie. Si c'est GitHub qui tombe, le script refuse d'écrire : la dernière version valide reste en ligne.

Le code est lisible et se lance en local :

```bash
GITHUB_TOKEN=$(gh auth token) node scripts/generate-observatory.mjs dist/observatory.svg
```

→ [`scripts/generate-observatory.mjs`](https://github.com/LaFicelleCmoi/LaFicelleCmoi/blob/main/scripts/generate-observatory.mjs) · [`.github/workflows/observatory.yml`](https://github.com/LaFicelleCmoi/LaFicelleCmoi/blob/main/.github/workflows/observatory.yml)

</details>

<details>
<summary><b>🧭 Lire la console (la légende)</b></summary>

<br>

| Élément | Signification |
|---|---|
| **Catalogue LC** | Mes dépôts classés au nombre de commits, comme un catalogue Messier — mesuré, pas choisi à la main |
| **Éclat** | La barre et le chiffre : le nombre de commits de l'objet |
| **Classe O / G / M** | Fraîcheur du dépôt, comme la température d'une étoile : **O** bleue et brûlante = poussé il y a moins de 3 semaines · **G** solaire = moins de 4 mois · **M** = refroidi |
| **Barre de couleur** | Le langage principal du dépôt, aux couleurs officielles GitHub |
| **Ciel profond** | Qualité du ciel pour les galaxies et nébuleuses : plus la Lune éclaire, plus elles pâlissent |
| **Courbe de lumière** | Mes contributions nuit par nuit sur 60 jours, avec la moyenne en pointillés et le plus gros **sursaut** marqué |

Tout est animé au CSS pur dans le SVG, et tout s'arrête si votre système demande `prefers-reduced-motion`.

</details>
